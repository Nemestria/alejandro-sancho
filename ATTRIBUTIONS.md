# Attributions

Third-party assets used in this project, and the terms they came under.

This file is the canonical list. The same list is shown in-app behind the
**CREDITS** button (`src/Credits.tsx`, data in `src/attributions.ts`) — a
licence that requires attribution is not satisfied by a repo file alone, since
most people who see the work will never open the repo. Add to both, or add to
`src/attributions.ts` and mirror it here.

## 3D models

### PSX Style Office Walls Pack

- **Author:** wooolvie
- **Source:** https://skfb.ly/pspOz
- **Licence:** [Creative Commons Attribution 4.0](http://creativecommons.org/licenses/by/4.0/)

> "PSX Style Office Walls Pack" (https://skfb.ly/pspOz) by wooolvie is licensed
> under Creative Commons Attribution (http://creativecommons.org/licenses/by/4.0/).

Used for the room's walls, and — reusing the same tile set — its ceiling.
Baked into `public/ArcadeFolio.glb`.

CC BY 4.0 permits modification and commercial use, and requires that credit,
a licence link, and an indication of any changes are given. The tiles are
re-scaled, re-lit and re-used as ceiling geometry in this project; that counts
as a change, and is stated here.
